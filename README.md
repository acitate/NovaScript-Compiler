# NovaScript+

NovaScript+ is a compiler project in progress. Its current stage provides a desktop interface for lexical analysis, showing tokens and source diagnostics.

## Run

Requires Python 3.14+ with Tkinter available. From the project directory, run:

```sh
uv run main.py
```

Open a `.ns` file or enter source in the editor, then select **Analyze**. Sample programs are in `samples/`.
